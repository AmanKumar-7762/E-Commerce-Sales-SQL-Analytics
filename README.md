#  E-Commerce Sales & Customer Analytics

## About the Project

This is an **E-Commerce Sales & Customer Analytics SQL Project** built using MySQL.

The project analyzes customers, products, orders, revenue, profit, discounts, payments, and cancellations.

##  Objectives

* Analyze sales performance
* Find top-selling products
* Analyze customer behavior
* Find revenue by category
* Identify repeat customers
* Find high-value customers
* Analyze cancellations
* Calculate monthly revenue and growth
